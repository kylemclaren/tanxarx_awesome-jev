# Contributing

Thanks for wanting to add to Awesome Jev! A few ground rules, in order of importance:

1. **The link must be real and live.** Before opening a PR, open the link yourself. Don't add a project because a tweet or thread *mentioned* its name — resolve the actual URL (including any `t.co` shortlink or "link in reply/comments") and confirm the repo/page exists.
2. **It has to actually be about Jev / TypeSafe AI.** A generic AI-agent tool that happens to appear in the same digest or search cluster doesn't belong here unless Jev is a real part of what it does.
3. **One entry per line**, format: `- [name](link) - Short, factual description ending in a period.` Keep descriptions to one sentence. No marketing language ("revolutionary", "game-changing", etc).
4. **Alphabetical or logical order** within a section — check the existing entries and match the pattern.
5. **New category?** Only add one if there are 3+ entries that don't fit existing sections; otherwise it goes under the closest existing heading.
6. If you're the author of the project, say so in the PR description — it's welcome, just be transparent about it.

Entries get removed if the linked project disappears, is archived with no clear relevance left, or turns out not to be about Jev after all. If you spot one like that, open an issue or PR to remove it.
